# Active Court

Active Court - PHP-система для управления спортивными площадками, клиентами, бронированиями, платежами, отчётами и устройствами спортивных объектов.

## Возможности

- бронирование кортов и управление доступностью площадок;
- регистрация клиентов, личный кабинет и управление аккаунтами;
- онлайн-оплата, скидки, купоны, билеты и абонементы;
- административные отчёты и управление контентом;
- интерфейсы сайта, touchscreen-терминалов, дисплеев и `mapi`;
- интеграция с внешними устройствами и сервисами.

## Требования

Серверное окружение проекта использует PHP 8.2. Полные требования и порядок настройки находятся в [инструкции по установке](.docs/installation/setup.md).

## Структура репозитория

| Путь | Назначение |
|---|---|
| `app/` | Конфигурация приложения, действия, маршруты, локализация и шаблоны |
| `core/modules/` | Прикладные и системные модули |
| `core/system/` | Общая инфраструктура и базовые компоненты |
| `engines/` | Существующие engine-классы проекта |
| `display/`, `touchscreen/`, `mapi/` | Device-specific точки входа |
| `.docs/` | Проектная документация |
| `bin/` | Кроссплатформенные CLI-команды проекта |

Проект использует собственный framework, Service Locator, модульную архитектуру, device actions и custom autoloading. Перед изменением существующего поведения необходимо изучить код соответствующего модуля и связанную документацию.

## Разработка

- Следуйте существующей архитектуре и локальному стилю кода.
- Используйте PHP 8.2 и сохраняйте совместимость с серверным окружением проекта.
- Не добавляйте пользовательские строки напрямую: используйте систему локализации.
- Тесты находятся в соседнем репозитории `../tests/` и запускаются командой `composer test`.
- Для нестандартного пути скопируйте `.actest.example.json` в `.actest.loc.json` и измените `testsRoot`.
- После структурных изменений документации запускайте:

      composer docs:check

Без Composer проверку можно запустить напрямую: `php bin/check-documentation`.

Для PowerShell можно установить быстрые команды:

    .\install-profile.ps1

После установки доступны `actest`, `acdocs`, `acroot` и `acprofile`. Подробности находятся в [руководстве по установке](.docs/installation/setup.md#быстрые-команды-powershell).

Обновление и перезагрузка текущего PowerShell-сеанса:

    acprofile -Update
    acprofile -Reload

Справка для любой быстрой команды: `<команда> h`, например `actest h` или `acprofile h`.

Подробные правила для Codex находятся в [AGENTS.md](AGENTS.md), правила ведения документации - в [соответствующем руководстве](.docs/development/documentation.md).
