# Документация Active Court

Active Court — PHP-система управления спортивными площадками, бронированиями, клиентами, платежами, счетами,
отчётами и устройствами самообслуживания.

Серверный runtime проекта: **PHP 8.2**.

## Карта приложения

| Путь | Назначение |
|---|---|
| `core/modules/` | Основные функциональные модули. |
| `core/system/` | Общие системные компоненты и custom framework. |
| `app/config/` | Конфигурация приложения. |
| `app/tpl/` | Общие шаблоны. |
| `engines/` | Legacy и вспомогательные движки. |
| `site/`, `widget/`, `touchscreen/`, `display/`, `mapi/` | Точки входа разных устройств и интерфейсов. |
| `../tests/` | Соседний репозиторий unit-тестов Codeception. |

## Работа с документацией

Перед изменением функциональности необходимо прочитать документацию затрагиваемого модуля и связанные
архитектурные документы. После изменения поведения документация обновляется в том же коммите.

README можно создавать как обзор или навигационный индекс. Подробные планы модульных функций хранятся рядом с
документацией модуля, активные задачи регистрируются в `tasks/README.md`, а завершённые документы переносятся в
`archive/`.
