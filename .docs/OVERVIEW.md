# Обзор документации Active Court

## Созданная документация

Я создал полную структуру документации для системы Active Court, которая включает в себя следующие разделы:

### 📁 Структура документации

```
docs/
├── README.md                           # Главная страница документации
├── overview.md                         # Этот файл - обзор документации
├── architecture/                       # Архитектура и основы
│   ├── overview.md                     # Обзор архитектуры системы
│   └── project-structure.md            # Структура проекта
├── installation/                       # Установка и настройка
│   └── setup.md                        # Руководство по установке
├── technical/                          # Техническая документация
│   └── service-locator.md              # Система сервисов
├── modules/                            # Документация модулей
│   ├── README.md                       # Обзор всех модулей
│   ├── reservations.md                 # Модуль бронирований
│   └── clients.md                      # Модуль клиентов
└── development/                        # Руководства для разработчиков
    ├── developer-guide.md              # Руководство разработчика
    └── testing.md                      # Unit-тесты (репозиторий tests/)
```

### 📚 Содержание документации

#### 1. Главная страница (`docs/README.md`)

- Навигация по всем разделам документации
- Быстрый поиск по функциям и компонентам
- Информация о поддержке и обновлениях
- Ссылки на все модули и технические разделы

#### 2. Архитектура (`docs/architecture/`)

- **overview.md** - Подробный обзор архитектуры системы 

  - Архитектурные принципы (модульность, Service Locator, MVC)
  - Ключевые компоненты (Service, App, BaseModule, Engines)
  - Поток выполнения запроса с диаграммой
  - Типы устройств (Site, Admin, Touch, Display, API)
  - Преимущества архитектуры

- **project-structure.md** - Детальная структура проекта
  - Описание всех папок и их назначения
  - Ключевые файлы системы
  - Принципы организации кода
  - Рекомендации по разработке

  - Обновление системы

### 📖 Как использовать документацию

#### Для новых разработчиков:

1. Начните с `docs/README.md` для общего понимания
2. Изучите `docs/architecture/overview.md` для понимания архитектуры
3. Прочитайте `docs/development/developer-guide.md` для стандартов разработки
4. Изучите конкретные модули в `docs/modules/`

#### Для администраторов:

1. Следуйте `docs/installation/setup.md` для установки
2. Изучите `docs/architecture/project-structure.md` для понимания структуры
3. Настройте систему согласно рекомендациям

#### Для интеграции:

1. Изучите `docs/technical/service-locator.md` для работы с API
2. Ознакомьтесь с модулями в `docs/modules/`
3. Используйте примеры кода для интеграции
