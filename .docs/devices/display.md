# Информационный дисплей

Информационный дисплей показывает текущее состояние площадок: свободные периоды, бронирования, абонементы, блокировки и уже прошедшее время. Страница предназначена для постоянного отображения на отдельном экране и автоматически обновляется без перезагрузки.

## Основные компоненты

| Компонент | Расположение | Назначение |
| --- | --- | --- |
| Страница дисплея | `display/index.php` | Формирует заголовок, часы и HTML-колонки площадок |
| Построение колонок | `core/ReservationsVisualizationCommon.php` | Загружает площадки и периоды, применяет правила видимости для устройства `display` |
| AJAX-обновление сайта | `assets/display/js/ajaxloadmodule.js` в репозитории сайта | Каждые 30 секунд загружает состояния периодов и обновляет ячейки |
| XML-источник данных | `display/reservations_visualization.php` | Возвращает состояния временных периодов на текущую дату |

Сайт подключает этот проект через `SHARED_PATH`, заданный в его `config.php` или `config.loc.php`. В рабочем окружении это обычно `/var/www/shared/main/`.

## Поток данных

1. `display/index.php` определяет разрешённые сочетания типа площадки и вида спорта. Основной источник настройки — `DISPLAY_TYPE`; если настройка отсутствует, используются типы по умолчанию.
2. `ReservationsVisualizationCommon::renderAreasTypeColumns()` получает активные площадки и формирует HTML-колонки.
3. Для устройства `display` сервер получает подходящее правило через `rulePriority()` и проверяет видимость колонки через `getVisibleColumnByRule()`.
4. После загрузки страницы `ajaxloadmodule.js` запрашивает `reservations_visualization.php`.
5. Полученный XML связывается с элементами страницы по идентификатору `timeBox_{area_id}_{period_number}`.
6. Запрос повторяется каждые 30 секунд. Часы на странице обновляются каждую секунду средствами браузера.

## Состояния периода

JavaScript назначает внутреннему элементу периода CSS-класс в зависимости от атрибутов XML:

| Условие | CSS-класс | Значение |
| --- | --- | --- |
| `blocked="1"` | `blocked` | Период заблокирован |
| `gone="1"` | `unAvailable` | Период уже прошёл |
| `ordered="1"` или `ticket="1"`, статус заказа `0` | `half` | Заказ ожидает подтверждения |
| `ordered="1"` или `ticket="1"`, подтверждённый статус | `ordered` | Период занят |
| Нет перечисленных состояний | `avaliable` | Период свободен |

Название класса `avaliable` содержит историческую опечатку и должно изменяться только одновременно в JavaScript и CSS.

## Настройки

- `DISPLAY_TYPE` — перечень отображаемых сочетаний `type_id_sport_id`.
- `DISPLAY_RENAME` — переименование площадок для дисплея.
- `HIDE_NAME_ON_DISPLAY` — скрытие имени клиента в XML дисплея.

## Текущие ограничения

- В `ajaxloadmodule.js` ID площадок заданы фиксированным массивом. Изменение площадок в базе или правилах требует ручного изменения JavaScript.
- XML-обработчик отдельно загружает площадки типов `1` и `2` и не использует тот же полный набор правил видимости, что HTML-страница.
- Из-за двух независимых источников списка HTML, JavaScript и XML могут содержать разные площадки.

Запланированное устранение ограничений описано в задаче [«Динамический список площадок дисплея»](../tasks/display-dynamic-area-ids.md).
