# Модуль membershipFees

Модуль отвечает за группы членских взносов, членские данные клиентов, юбилейные списки, отчёты по составу
участников и формирование членских счетов.

## Административный раздел Vereinsverwaltung

Раздел доступен при включённом `MembershipFeesConfig::useMembershipFees()` и требует уровень доступа `2`.
Его корневой адрес — `membershipFees/management`. В верхнем меню раздел располагается между клиентами и
праздничными днями. Отдельное поле структуры `menu_title` задаёт компактную двухстрочную подпись верхнего меню,
не изменяя заголовок страницы.

Внутри раздела доступны семь страниц:

| Страница | Адрес | Реализация |
|---|---|---|
| Настройка членских взносов | `membershipFees/management` | `MembershipFeesManagementController::show()` |
| Группы взносов | `membershipFees/groups?vereinsverwaltung=1` | существующий контроллер групп |
| Юбиляры | `membershipFees/anniversary?vereinsverwaltung=1` | существующий контроллер юбиляров |
| Участники по годам рождения | `membershipFees/management/membersByYearOfBirth` | отдельная форма существующего отчёта |
| Состав участников | `membershipFees/management/membership` | отдельная форма существующего отчёта |
| Членские счета | `membershipFees/accounts?vereinsverwaltung=1` | существующий контроллер счетов |
| Экспорт клиентов | `clients.php?action=viewExportFormClients&vereinsverwaltung=1` | существующий экспорт клиентов |

Параметр `vereinsverwaltung=1` изменяет только навигационный контекст и возвратные ссылки. Адреса без него
сохраняют прежнее поведение и расположение в административном меню.

Отдельные формы двух отчётов оборачиваются классом `membership-fees-management-report`, который центрирует их
только внутри нового раздела и не изменяет общую страницу отчётов.

## Назначение группы клиенту

Форма `membershipFees/management` получает активных клиентов через `clients/Clients/getListNamesClients` в
системе modComm. Активные группы загружаются моделью `MembershipFeesGroupsModel`.

При сохранении `ClientDataModel::assignMembershipFeesGroup()` обновляет либо создаёт единственную запись:

- `typeBlock = membershipFees`;
- `name = membership_fees_group`;
- `client_id` — идентификатор выбранного клиента;
- `value` — идентификатор группы или `0`, если группа снята.

Схема базы данных не изменяется. Контроллер до сохранения проверяет уровень доступа, наличие активного клиента
и наличие выбранной активной группы.

## Совместимость

- Старые страницы групп, юбиляров, отчётов, счетов и экспорта продолжают работать.
- Существующие классы, методы и их параметры не переименованы и не удалены.
- Для отчётов добавлены отдельные публичные методы-обёртки над существующими защищёнными построителями форм.
- Создание пользователя из нового раздела использует существующий legacy-сценарий `clients.php` и сохраняет
  контекст нового меню.
