# Модуль webIo

## Назначение

Модуль связывает Active Court с внешними устройствами через Web I/O.

## Текущее состояние

Интеграция используется существующими устройствами. Расширение для управления локерами находится на стадии планирования.

## Основные компоненты

- Код модуля: `core/modules/webIo/`.
- Команды и состояния устройств обрабатываются через существующие точки интеграции проекта.
