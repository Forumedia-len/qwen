# Модуль modComm

## Назначение

Модуль организует внутреннюю коммуникацию между модулями, контроллерами и обработчиками действий Active Court.

## Текущее состояние

Механизм используется существующими модулями для вызова действий без прямого связывания их реализаций.

## Основные компоненты

- Код модуля: `core/modules/modComm/`.
- Обработчики располагаются в принятых проектом каталогах `controllers/modComm/`.
- Вызовы выполняются через существующую инфраструктуру модулей и Service Locator.
