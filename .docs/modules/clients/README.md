# Модуль clients

## Назначение

Модуль управляет клиентами Active Court: регистрацией, авторизацией, профилем и клиентскими сценариями личного кабинета.

## Текущее состояние

Модуль используется приложением и поддерживает публичные, административные и персональные клиентские сценарии.

## Основные компоненты

- Код модуля: `core/modules/clients/`.
- Точка входа: `ClientsModule`.
- Контроллеры, модели и представления разделены по принятой структуре модулей.
