# Модуль payment

## Назначение

Модуль отвечает за онлайн-оплату, статусы платёжных операций и интеграцию с внешними провайдерами.

## Текущее состояние

Текущая реализация поддерживает существующие сценарии PayPal и Payone. Переход PayPal на REST API находится на стадии планирования.

## Основные компоненты

- Код модуля: `core/modules/payment/`.
- Параметры провайдеров берутся из конфигурации приложения.
- Платёжные сценарии связаны с бронированиями и клиентскими аккаунтами.
