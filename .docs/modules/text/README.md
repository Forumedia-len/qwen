# Модуль text

## Назначение

Модуль управляет локализованным текстовым контентом и его редактированием в административном интерфейсе.

## Текущее состояние

Модуль используется для хранения, выбора и редактирования текстов с учётом языка приложения.

## Основные компоненты

- Код модуля: `core/modules/text/`.
- Данные организованы по существующей модели текстовых записей и переводов.
- Административные действия используют общую инфраструктуру модулей.
