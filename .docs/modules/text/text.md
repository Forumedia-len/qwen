# Модуль `text`

## Назначение

Модуль `text` отвечает за хранение и отображение статических текстов, которые используются на публичных страницах (контакты, прайс, политика конфиденциальности и т.д.). Тексты сохраняются в таблице `AC\core\modules\text\engines\config_text` и могут быть переиспользованы на сайте, в почтовых шаблонах и вспомогательных страницах.

## Административный интерфейс

- **URL:** `at/text/alias/{alias}` (например, `at/text/alias/address`)
- **Структура меню:** пункты `config_text_*` в админке указывают на соответствующие alias
- **Контроллер:** `core/modules/text/controllers/admin/TextController.php`
- **Представление:** `core/modules/text/views/admin/default/form.php`

### Возможности

- Просмотр и редактирование контента в WYSIWYG-редакторе (CKEditor)
- Переключение между alias через выпадающий список
- Вкладки по активным языкам: содержимое на языке по умолчанию обязательно, переводы задаются на вкладках
- При отсутствии перевода движок подставит значение с языка по умолчанию
- Сохранение контента напрямую в таблицу `AC\core\modules\text\engines\config_text` через модель `TextModel`

### Конфигурация системных сообщений

- **URL:** `at/text/messages/device/{device}/courtType/{alias}`
- **Контроллер:** `core/modules/text/controllers/admin/TextMessagesController.php`
- **Назначение:** редактирование содержимого `message.{lang}.ini` для разных типов кортов и устройств
- **Особенности:**
  - группировка сообщений по разделам структуры переводов
  - переключение между устройствами (site/touch) через контент-меню
  - фильтр по типу кортов (`common` + активные типы из `AreasModel::selectActiveType()`)
  - редактор CKEditor и быстрый просмотр доступных плейсхолдеров (`{{variable}}`)
  - сохранение в INI-файлы через `IniFiles` с мгновенным применением
  - при сохранении локальные файлы содержат только изменённые ключи, поэтому базовые системные сообщения не копируются целиком

### Структура данных

| Поле   | Описание                                         |
|--------|--------------------------------------------------|
| alias  | Уникальный идентификатор текста (`address`, …)   |
| content| HTML-содержимое, отображаемое на клиентских страницах |
| language | Код языка, к которому относится запись (`de`, `en` и т.д.) |

## Основные классы

| Класс | Роль |
|-------|------|
| `TextController` | Админ-контроллер: маршрутизация, проверка alias, работа с табами языков |
| `TextModel` | Доступ к данным `config_text`, загрузка/сохранение локализованных записей |
| `TextDto` | DTO с alias, содержимым и кодом языка |

## Расширение

1. Добавьте новую запись в таблицу `config_text` (alias + язык; для языка по умолчанию обязательна базовая запись).
2. Для каждого дополнительного языка строка создаётся автоматически при сохранении формы администратора.
3. Создайте пункт меню в `app/structure/structure.admin.php` (или соответствующем модульном файле) с `href = 'text/alias/{alias}'`.
4. Текст сразу станет доступным в интерфейсе редактирования и на страницах, где используется соответствующий alias.
