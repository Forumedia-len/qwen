# Модуль reservations

## Назначение

Модуль управляет бронированиями спортивных площадок, доступностью кортов и связанными пользовательскими сценариями.

## Текущее состояние

Модуль является рабочей частью приложения и используется сайтом, административным интерфейсом и устройствами. Общие ресурсы всплывающих окон используются несколькими поверхностями приложения.

## Основные компоненты

- Код модуля: `core/modules/reservations/`.
- Контроллеры и действия разделены по устройствам и режимам приложения.
- Бронирования интегрированы с клиентами, платежами, зонами и билетами.
