# Модуль mailing

## Назначение

Модуль формирует и отправляет почтовые рассылки клиентам Active Court.

## Текущее состояние

Поддерживаются модель данных рассылок, административный интерфейс и резервный механизм отправки.

## Основные компоненты

- Код модуля: `core/modules/mailing/`.
- Отправка использует почтовый engine проекта.
- Управление рассылками доступно в административном интерфейсе.
