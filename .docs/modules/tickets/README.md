# Модуль tickets

## Назначение

Модуль управляет билетами и абонементами, сроками их действия и ограничениями использования.

## Текущее состояние

Основные сценарии создания и применения абонементов реализованы. Изменения пересечений билетных блокировок внедрены в код, но требуют завершения эксплуатационного развёртывания.

## Основные компоненты

- Код модуля: `core/modules/tickets/`.
- Данные билетов и абонементов хранятся в профильных таблицах проекта.
- Проверки использования связаны с бронированиями, блокировками и праздничными периодами.
