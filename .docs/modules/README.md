# Модули Active Court

Каталог документации по прикладным и системным модулям. Общие правила устройства модулей, загрузки контроллеров и моделей описаны в [архитектуре модулей](modules.md).

| [mailing](mailing/README.md) | Почтовые рассылки и административный интерфейс рассылок |

| [modComm](mod-comm/README.md) | Коммуникация между модулями и обработчиками действий |
| [payment](payment/README.md) | Онлайн-платежи и интеграции с платёжными провайдерами |
| [reservations](reservations/README.md) | Бронирования, корты и связанные сценарии |
| [text](text/README.md) | Управление локализованным текстовым контентом |

## Правила сопровождения

- `README.md` раздела служит кратким индексом и не заменяет тематические документы.
- Активные планы регистрируются в [перечне задач](../tasks/README.md).
- Завершённые планы и отчёты переносятся в [архив](../archive/README.md).
- Общие требования к документации определены в [руководстве](../development/documentation.md).
