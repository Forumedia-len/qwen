# CLIENTS-002: масштабирование CSV-экспорта клиентов

**Статус:** запланировано  
**Модули:** `clients`, `cron`  
**Полное описание:** [CSV-экспорт клиентов](../modules/clients/client-export.md#планируемое-масштабирование)

## Результат

Обеспечить формирование и доставку CSV-экспорта для 500 000 и более клиентов
без загрузки всей клиентской базы и готового CSV в память и без отдельного
SQL-запроса истории бронирований для каждого клиента.

## Основные задачи

1. Читать клиентов устойчивыми порциями по `client_id`, а не одним массивом.
2. Получать последние и следующие бронирования одним пакетным запросом на порцию.
3. Записывать BOM, заголовок и строки непосредственно во временный файл через поток.
4. Использовать корректное CSV-экранирование полей с разделителем `;`.
5. Сохранить потоковую отправку локального файла через `DeployFile::deploy()`.
6. Добавить защиту от параллельного запуска, обработку незавершённых файлов и
   понятный итог выполнения.
7. Проверить время, пиковую память и целостность результата на объёме не менее
   500 000 клиентов.

Сравнение через `downloadContents()` в эту задачу не входит: имя каждого
экспорта содержит дату и время, поэтому удалённый файл является новым артефактом.
