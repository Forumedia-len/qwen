# Реестр предполагаемых улучшений

Здесь хранится короткий перечень задумок и ещё не реализованных изменений.
Подробное техническое описание остаётся в документации соответствующего
модуля, а отдельная карточка помогает быстро найти будущую работу.

## Правила ведения

- одна задумка — один файл с коротким названием в `kebab-case`;
- в карточке указываются статус, затрагиваемый модуль, ожидаемый результат,
  основные задачи и ссылка на полное описание;
- подробности процесса и архитектуры не дублируются;
- после реализации статус меняется на `реализовано`, а карточка дополняется
  ссылкой на итоговую документацию или миграцию;
- отменённые задумки не удаляются: им назначается статус `отменено` с краткой
  причиной.

Рекомендуемые статусы: `идея`, `запланировано`, `в работе`, `реализовано`,
`отменено`.
