# WEBIO-001: аудит генерации и доставки календарей

**Статус:** идея  
**Модули:** `webIo`, `lockers`  
**Связанная документация:** [Модуль WebIO](../modules/webIo/webio.md)

## Результат

Показывать в админке текущее состояние календарей площадок и шкафчиков,
значимые изменения расписания и результат FTP-доставки без записи каждого
одинакового HTTP-запроса и без сохранения персональных данных из `.ics`.

## Основные задачи

1. Разделить технические ошибки, команды устройству и долговременный аудит календарей.
2. Ввести устойчивый ключ календаря и семантический hash нормализованных событий.
3. Хранить текущее состояние отдельно от истории изменений и повторяющихся ошибок.
4. Различать сформированный и фактически доставленный FTP-вариант файла.
5. Добавить сводку cron, фильтры и состояние доставки в админку.
6. Подготовить идемпотентную миграцию, политику хранения и тесты конкурентных обновлений.

Реализацию предлагается выполнять поэтапно: сначала структурированные ошибки и
`request_id`, затем состояние FTP/cron-календарей, после этого история изменений,
HTTP-агрегация и административный интерфейс.
