# CLIENTS-001: отдельные поля снимков баланса

**Статус:** запланировано  
**Модуль:** `clients`  
**Полное описание:** [Личный счёт клиента и снимки баланса](../modules/clients/private-account.md#предполагаемые-обновления)

## Результат

Хранить `balance_before` и `balance_after` в отдельных полях
`DECIMAL(12,2)`, использовать `related_data` только для дополнительного
контекста и перевести `clients.prepayment_sum` с `DOUBLE` на `DECIMAL(12,2)`.

## Основные задачи

1. Добавить nullable-поля снимков в `private_account_transactions`.
2. Обновить движок, модель таблицы, DTO, API и тесты.
3. Обеспечить временную совместимость со снимками в `related_data`.
4. Перенести и проверить исторические снимки.
5. Отдельной миграцией изменить тип `clients.prepayment_sum`.
6. После обновления всех сайтов прекратить запись снимков в `related_data`.

Миграция снимков и изменение типа текущего баланса должны оставаться двумя
независимыми этапами с отдельной проверкой и возможностью отката.
