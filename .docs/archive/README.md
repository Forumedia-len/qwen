# Архив документации

Архив содержит отчёты о выполненной работе и документы завершённых задач. Активные планы остаются в
`../tasks/` или в документации соответствующих модулей.

| Раздел | Содержание |
|---|---|
| [reports/](reports/README.md) | Отчёты о выполненной работе и исторические Cursor-отчёты. |
| [tasks/](tasks/README.md) | Завершённые задачи и исторический список выполненных работ. |

Архивные документы не удаляются при устаревании. При необходимости в них добавляется ссылка на актуальную
документацию, но историческое содержание не переписывается как текущее состояние системы.
