## Структура документации

### Классы
- **ModCommModuleInterface** - Интерфейс для модулей с межмодульным взаимодействием
- **ModCommModule** - Основной модуль для обработки межмодульных запросов
- **ModCommController** - Базовый контроллер для обработки запросов
- **ModCommService** - Сервис для межмодульного общения (Singleton)
- **ModCommRequest** - Класс для представления входящих запросов
- **ModCommResponse** - Класс для представления ответов модулей
- **ModCommHelper** - Хелпер с утилитарными методами
- **ModCommException** - Специализированные исключения модуля

### Основные возможности
- Межмодульное взаимодействие через JSON запросы
- Автоматическая валидация и авторизация
- Логирование всех операций
- Обработка ошибок и исключений
- Поддержка метаданных и временных меток
