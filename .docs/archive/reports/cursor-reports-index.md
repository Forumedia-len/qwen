# Исторический реестр Cursor-отчётов

> Документ сохранён как исторический расширенный индекс. Актуальный список архивных отчётов находится в
> [README.md](README.md).

## Обзор

Папка `reports/` содержит все отчеты о работе, изменениях и обновлениях в проекте Active Court. Отчеты создаются для документирования важных изменений, рефакторинга и новых функций.

## Структура отчетов

### Правила именования

- **Формат**: `{тип-изменения}-{описание}-report.md`
- **Регистр**: нижний регистр
- **Разделители**: дефисы (-)
- **Примеры**:
  - `documentation-restructuring-report.md`
  - `feature-implementation-report.md`
  - `bug-fix-report.md`
  - `performance-optimization-report.md`

### Структура отчета

Каждый отчет должен содержать:

1. **Заголовок** - краткое описание изменений
2. **Дата создания** - когда был создан отчет
3. **Выполненные изменения** - подробное описание
4. **Преимущества** - что улучшилось
5. **Следующие шаги** - что планируется дальше
6. **Заключение** - итоги работы

## Создание нового отчета

При создании нового отчета следуйте шаблону:

```markdown
# [Название отчета]

## Дата создания

[Дата]

## Описание

[Краткое описание изменений]

## Выполненные изменения

### 1. [Категория изменений]

- [Описание изменения]
- [Описание изменения]

### 2. [Категория изменений]

- [Описание изменения]
- [Описание изменения]

## Преимущества

- [Преимущество 1]
- [Преимущество 2]

## Следующие шаги

1. [Планируемый шаг 1]
2. [Планируемый шаг 2]

## Заключение

[Итоги работы]
```

## Правила работы с отчетами

1. **Создавать отчеты** для значимых изменений
2. **Обновлять этот README** при добавлении новых отчетов
3. **Использовать единый формат** для всех отчетов
4. **Включать дату создания** в каждый отчет
5. **Описывать преимущества** и следующие шаги
