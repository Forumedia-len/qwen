## Новые разделы документации

### Система личных счетов (PrivateAccount)

**Описание**: Полная документация по системе управления личными счетами клиентов.

**Содержание**:
- PrivateAccountTransactionEngine - основной движок
- PrivateAccountTransactionDto - объект передачи данных
- Примеры использования для пополнения и списания
- Интеграция с платежными системами
- Логирование и мониторинг операций

**Ключевые возможности**:
- Пополнение лицевого счета
- Списание средств со счета
- История транзакций
- Управление статусами транзакций
- Расчет баланса клиента

### API и межмодульное общение (modComm)

**Описание**: Документация по API взаимодействию через систему modComm.

**Содержание**:
- PrivateAccountController - структура и конфигурация
- Все доступные методы API с примерами
- Правила авторизации и валидации
- Обработка ошибок и HTTP статусы
- Интеграция с другими модулями

**Доступные методы**:
- `transactions` - получение истории транзакций
- `deposit` - пополнение счета
- `withdraw` - списание средств
- `listIn` - получение только пополнений
- `listOut` - получение только списаний
- `changeStatus` - изменение статуса транзакции

## Технические детали

### Архитектура модуля

**Основные компоненты**:
- ClientsModule - основной класс модуля

- PrivateAccountController - modComm контроллер

**Пути загрузки**:

- modComm контроллеры: `core/modules/clients/controllers/modComm/`
- Движки: `core/modules/clients/engines/`
- Модели: `core/modules/clients/models/`

### Интеграция с modComm

**Автоматическая загрузка**: Контроллеры автоматически загружаются через систему modComm

**Авторизация**: Различные уровни доступа для разных ролей пользователей

**Валидация**: Строгие правила проверки входных данных для всех методов

**Стандартизация**: Единообразные ответы API с HTTP статусами

## Примеры использования

### Работа с PrivateAccount

```php
// Получение движка
$transactionEngine = getEngine('privateAccountTransaction');

// Пополнение счета
$transactionId = $transactionEngine->deposit($transactionDto);

// Получение транзакций клиента
$transactions = $transactionEngine->getTransactionsByClient($clientId);
```

### Использование modComm API

```php
// Получение транзакций через API
$response = $service->sendRequest('clients', 'PrivateAccount/transactions', [
    'clientId' => 123,
    'typeDirection' => 'in'
]);
```
