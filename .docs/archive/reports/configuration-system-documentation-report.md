### ✅ 3. Документирование функции uses()

**Подробно описано**:
```php
function uses(): void
{
  foreach (func_get_args() as $lib) {
    foreach (array_merge(Service::autoloader()->getNamespace(),
      ['SharedUses' => pathAs((str_starts_with(SHARED_PATH, SHARED) ? SHARED : dirname(SHARED_PATH) . '/'))]) as $path) {
      foreach (['.loc', ''] as $filePrefix) {
        if ($file = Service::autoloader()->getPathFile(paths()->constantDir . $lib . $filePrefix, 'php', $path)) {
          Service::autoloader()->loadFile($file);
        }
      }
    }
  }
}
```

**Алгоритм работы**:
1. Получение путей поиска из автозагрузчика
2. Приоритетный поиск файлов с суффиксом `.loc`
3. Fallback к основным файлам
4. Загрузка через `Service::autoloader()->loadFile()`

## Ключевые особенности системы

### 1. Приоритетная система файлов

```php
// Порядок поиска для uses('mysql.config'):
// 1. mysql.config.loc.php (локальная конфигурация)
// 2. mysql.config.php (основная конфигурация)
```

### 2. Условное определение констант

```php
// Локальный файл может переопределить константы из основного
defined('LOCAL_SERVER') || define('LOCAL_SERVER', false); // основной файл
defined('LOCAL_SERVER') || define('LOCAL_SERVER', true);  // локальный файл (приоритет)
```

### 3. Интеграция с автозагрузчиком

```php
// Поиск по всем зарегистрированным путям автозагрузчика
Service::autoloader()->getNamespace();
// Результат: ['site/', 'dev/', 'vendor/', ...]
```

### 4. Поддержка сред выполнения

**Продакшен**:
- Только основные файлы (.php)
- `LOCAL_SERVER = false`
- Безопасные настройки

**Локальная разработка**:
- Локальные файлы (.loc.php) переопределяют основные
- `LOCAL_SERVER = true`
- Отладочные настройки

## Типы конфигурационных файлов

### Корневые конфигурации
- `site/config.php` / `site/config.loc.php` - публичная часть
- `dev/config.php` - разработческая часть

### Модульные конфигурации (app/uses/)
- `mysql.config.php` / `mysql.config.loc.php` - БД
- `authorization.php` / `authorization.loc.php` - авторизация
- `defined.php` / `defined.loc.php` - системные константы
- `baseConstants.php` / `baseConstants.loc.php` - базовые константы

### Основные константы системы

#### Пути и директории
```php
defined('ROOT_PATH')     || define('ROOT_PATH', '/path/to/site/');
defined('SHARED_PATH')   || define('SHARED_PATH', '/path/to/shared/');
```

#### Веб-конфигурация
```php
defined('HOST_NAME')     || define('HOST_NAME', 'example.com');
defined('BASE_HREF')     || define('BASE_HREF', 'https://example.com/');
defined('SESSION_COURT') || define('SESSION_COURT', 'session_name');
```

#### База данных
```php
defined('DB_HOST')          || define('DB_HOST', 'localhost');
defined('DB_DATABASE_NAME') || define('DB_DATABASE_NAME', 'database');
defined('DB_TABLE_PREFIX')  || define('DB_TABLE_PREFIX', 'prefix_');
```

## Лучшие практики

### 1. Создание конфигурационных файлов
- Всегда использовать условное определение констант
- Группировать логически связанные константы
- Комментировать назначение констант

### 2. Локальная разработка
- Создавать .loc.php файлы для локальных настроек
- Не коммитить локальные файлы в репозиторий
- Использовать .gitignore для исключения

### 3. Безопасность
- Не сохранять пароли в основных файлах
- Комментировать чувствительные настройки в .loc.php
- Использовать переменные окружения для секретов

## Примеры использования

### Базовая конфигурация
```php
// site/config.php (основная)
defined('HOST_NAME')     || define('HOST_NAME', 'active-court.com');
defined('LOCAL_SERVER')  || define('LOCAL_SERVER', false);

// site/config.loc.php (локальная)
defined('HOST_NAME')     || define('HOST_NAME', 'ac.loc');
defined('LOCAL_SERVER')  || define('LOCAL_SERVER', true);
```

### Автоматическая загрузка
```php
// В bootstrap.php
uses('defined', 'mysql.config', 'authorization');

// Автоматически найдет и загрузит файлы в приоритетном порядке
```
