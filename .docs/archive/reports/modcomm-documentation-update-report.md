## Примеры использования

### Создание контроллера
```php
class UserController extends ModCommController
{
    protected function initializeCustomMethods(): void
    {
        $this->addMethod('getUsers', [
            'description' => 'Получить список пользователей',
            'requires_auth' => true
        ]);
        $this->addAuthorizationRule('getUsers', ['admin', 'manager']);
    }
}
```

### Использование сервиса
```php
$service = ModCommService::getInstance();
$response = $service->sendRequest('clients', 'User/getUsers', [
    'limit' => 20
], [
    'user_role' => 'admin'
]);
```

## Рекомендации по использованию

1. **Создание контроллеров** - использовать только `core/modules/{имя_модуля}/controllers/modComm/`
2. **Наследование** - все контроллеры должны наследоваться от `ModCommController`
3. **Валидация** - обязательно определять правила валидации для параметров
4. **Авторизация** - явно указывать правила доступа для каждого метода
5. **Логирование** - использовать встроенную систему логирования
