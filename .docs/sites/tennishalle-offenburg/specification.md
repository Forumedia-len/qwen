## Техническая архитектура

### Модули системы

1. **Reservation Module**

   - Основной модуль с кастомизациями
   - Управление бронированиями Ball Machine
   - Формирование названий классов

2. **Areas Module**

   - Управление кортами и оборудованием
   - Конфигурация типов оборудования
   - Интеграция с Ball Machine

3. **Clients Module**
   - Управление клиентами клуба
   - Профили пользователей
   - История бронирований

### Компоненты системы

1. **Классы формирования названий**

   - Автоматическая генерация имен контроллеров
   - Поддержка новых типов оборудования
   - Локализация названий

2. **Интерфейс пользователя**

   - Отображение Ball Machine в календаре
   - Формы бронирования
   - Статусы оборудования

3. **Бизнес-логика**
   - Правила бронирования
   - Расчет стоимости
   - Валидация данных
