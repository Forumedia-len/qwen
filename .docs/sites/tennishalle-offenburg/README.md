## Основные особенности

### Новый тип оборудования - Ball Machine

Сайт использует кастомизированный тип оборудования "Ball Machine" для автоматических теннисных машин.

**Статус**: Требует доработки  
**Модуль**: Reservation  
**Компонент**: Классы формирования названий

### Локальные настройки

- Кастомизация модуля Reservation для поддержки нового типа оборудования
- Локальные настройки отображения и бронирования
- Специфичные для теннисного клуба функции
