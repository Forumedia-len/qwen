# Архитектура системы Active Court

## Обзор архитектуры

**Active Court** - это модульная PHP-система для управления спортивными кортами, построенная на принципах MVC (Model-View-Controller) с использованием паттерна Service Locator и модульной архитектуры.

## Основные принципы архитектуры

### 1. Модульность

- Каждый функционал вынесен в отдельный модуль
- Модули независимы друг от друга
- Поддержка плагинной архитектуры

### 2. Service Locator Pattern

- Централизованный доступ к сервисам через `Service` класс
- Синглтон-паттерн для сервисов
- Автоматическое управление зависимостями

### 3. Автоматическая загрузка классов

- PSR-4 совместимый автозагрузчик
- Поддержка множественных пространств имен
- Приоритетная система загрузки

### 4. Мультиплатформенность

- Поддержка различных типов устройств
- Адаптивные интерфейсы
- Единая бизнес-логика

## Структура системы

### Ядро системы (`core/system/`)

#### Основные компоненты

**App.php** - Главный класс приложения

- Управление жизненным циклом приложения
- Обработка HTTP-запросов
- Определение типа устройства
- Выполнение соответствующих действий

**Services.php** - Service Locator

- Централизованный доступ к сервисам
- Управление зависимостями
- Синглтон-паттерн для сервисов

**Autoloader.php** - Автозагрузчик классов

- PSR-4 совместимость
- Поддержка множественных пространств имен
- Приоритетная система загрузки

#### Подсистемы

**HTTP подсистема** (`http/`)

- `request/` - Обработка HTTP-запросов
- `response/` - Формирование HTTP-ответов
- `url/` - Работа с URL и URI

**База данных** (`db/`)

- Query Builder
- ORM-подобная система
- Поддержка транзакций

**Маршрутизация** (`router/`)

- RESTful маршруты
- Модульная маршрутизация
- Middleware поддержка

**Сессии** (`session/`)

- Управление сессиями
- Безопасность
- Кэширование

**Валидация** (`validators/`)

- Валидация входных данных
- Правила валидации
- Обработка ошибок

**Логирование** (`log/`)

- Структурированное логирование
- Различные уровни логирования
- Ротация логов

**Отладка** (`debug/`)

- Обработка исключений
- Отладочная информация
- Профилирование

### Движки (Engines)

**Engines.php** - Главный класс движков

- Централизованный доступ к движкам
- Инициализация всех движков
- Управление зависимостями между движками

#### Основные движки

**AreasEngine** - Управление зонами и кортами

- CRUD операции для кортов
- Управление типами кортов
- Работа с расписанием

**ClientsEngine** - Управление клиентами

- Регистрация и авторизация
- Профили клиентов
- История бронирований

**ReservationsEngine** - Управление бронированиями

- Создание и отмена бронирований
- Проверка доступности
- Расчет цен

**UsersEngine** - Управление пользователями

- Система прав доступа
- Административные функции
- Управление ролями

**AccountsEngine** - Управление аккаунтами

- Финансовые операции
- Счета и платежи
- Отчетность

### Модули (`core/modules/`)

#### Структура модуля

```
module_name/
├── ModuleNameModule.php    # Главный класс модуля
├── controllers/            # Контроллеры
├── models/                 # Модели данных
├── views/                  # Представления
├── tables/                 # Структуры таблиц БД
├── actions/                # Действия для устройств
├── config/                 # Конфигурация модуля
└── structure/              # Структурные файлы
```

**reports** - Отчеты

**users** - Пользователи

## Расширяемость

### Создание нового модуля

1. Создать структуру папок
2. Наследовать от BaseModule
3. Реализовать контроллеры и модели
4. Добавить маршруты
5. Создать представления

### Создание нового движка

1. Наследовать от BaseEngine
2. Реализовать основные методы
3. Зарегистрировать в Engines
4. Добавить конфигурацию

### Создание нового устройства

1. Наследовать от DeviceActionInterface
2. Реализовать методы интерфейса
3. Добавить в систему маршрутизации
4. Создать соответствующие шаблоны

## Конфигурация

### Основные файлы конфигурации

- `config.php` - Основные настройки
- `AppConfig.php` - Настройки приложения
- `DBConfig.php` - Настройки базы данных
- `AuthConfig.php` - Настройки авторизации
- `LangConfig.php` - Языковые настройки

### Переменные окружения

- `HOST_NAME` - Имя хоста
- `BASE_HREF` - Базовый URL
- `SESSION_COURT` - Имя сессии
- `LOCAL_SERVER` - Флаг локального сервера
