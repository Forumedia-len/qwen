# ADR-002: Кроссплатформенные CLI-команды проекта

> **Статус:** принято  
> **Дата:** 2026-08-24  
> **Область:** инструменты разработки и CI  
> **Заменяет:** PowerShell-only запуск проверки документации

## Контекст

Основная разработка Active Court выполняется в Windows, а автоматические проверки и серверное окружение используют Linux. PowerShell-скрипт создавал дополнительную зависимость от `pwsh` и не соответствовал уже применённой в ветке `mc_box` структуре Composer с командой `bin/actest`.

## Рассмотренные варианты

- Сохранить PowerShell и отдельно написать shell-скрипт для Linux.
- Хранить реализацию в `tools/` и добавить платформенные wrapper-файлы.
- Использовать PHP 8.2 для общих CLI-команд и разместить запускаемые entrypoint-файлы в `bin/`.

## Решение

- Самостоятельные команды разработчика и CI размещаются в `bin/`.
- Общие команды пишутся на PHP 8.2 и запускаются как `php bin/<command>`.
- В Linux entrypoint может запускаться напрямую через shebang `#!/usr/bin/env php`.
- Composer предоставляет стабильные алиасы команд, например `composer test` и `composer docs:check`.
- Windows может предоставлять короткие PowerShell-команды через управляемый профиль, но они только делегируют вызов каноническим `bin/*`.
- PowerShell-команда определяет Active Court worktree из текущего каталога при каждом вызове и не использует worktree установки как неявный fallback.
- Версионируемый профиль хранится в Git, а установщик развёртывает его копию в `%LOCALAPPDATA%\ActiveCourt\PowerShell`; пользовательский профиль не ссылается на конкретный worktree.
- Обновление установленной копии выполняется явно с проверкой версии, защитой от downgrade и возможностью rollback.
- `tools/` резервируется для внутренних библиотек, генераторов и ресурсов, которые не являются самостоятельными командами.

## Последствия

- Одна реализация работает в Windows и Linux.
- Для общих проверок не требуются PowerShell, Bash или отдельные платформенные версии.
- PowerShell-профиль остаётся необязательным удобством и может обновляться независимо от CLI-реализации.
- CLI-файлы в `bin/` должны сохранять executable-bit для Linux.
- Команды используют серверную версию PHP 8.2 и не должны требовать более новую версию.
